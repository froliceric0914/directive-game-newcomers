# 新参者 · 人形町七日

## 镜头与设备适配

地图视窗保持正方形，按可用宽度及屏幕高度调整；街区相对坐标不变。移动时镜头跟随玩家，靠近店铺时优先框住整家店和玩家。地图边缘预留镜头空间，窗口尺寸变化时重新取景。手机和平板窄屏手帐在地图下方展开，避免遮挡访问中的店铺。

## 快捷键

- 方向键：逐格移动；阅读面板中保留原生滚动。
- E：访问附近店家或地标，展开当前地点的手帐；不在入口附近时只提示，不传送。
- J：展开／收起手帐。
- R：打开原文试读。
- Esc：先关闭阅读面板，再按可收起手帐。

忽略输入框、可编辑内容、输入法组合输入和系统组合键；按住快捷键不会反复切换。逻辑推理机制暂时搁置。

## 运行

使用任意静态服务器提供 `dist/`，例如 `python3 -m http.server 4173 --directory dist`。

## 内容与机制

- 三条示意街区、九个可访问地点，点击店铺或使用左右方向键切换街道。
- 每天六点调查精力，漫游、重读与推理不耗精力。
- 证言和证据组合解锁三个人物追问。线索和人物内容见 `dist/data.mjs`。
- 每日总结支持一段自由记录及最多三条证据。进度保存到当前浏览器 localStorage。
- 第七日日终截止，可提前提交完整答案，成功结局要求凶手、动机和三条证据均成立。
- `dist/engine.mjs` 保存纯状态规则，`dist/app.js` 实现交互，`dist/style.css` 实现响应布局。
- 街景图片由 ImageGen 生成，为艺术化想象，三街区共用一幅插画，非实景复原。

### 桌面快捷键（macOS / Windows）

| 场景 | 按键 | 操作 |
| --- | --- | --- |
| 街道 | 方向键 / E / J / R / H | 连续移动 / 访问 / 手帐 / 阅读 / 回到车站 |
| 店内 | T / J / R | 对话 / 开关手帐 / 原著 |

按钮显示快捷键与 `aria-keyshortcuts`；触控设备隐藏键帽提示，外接键盘仍可使用。Command、Ctrl、Alt 组合键与输入框输入不被拦截。店内快捷键按当前面板分配，不会同时移动地图；长按非移动快捷键不重复执行。

### 导览图缩放

导览图标题旁增加 − / + 控件及当前缩放比例，支持 50%–200%，每次调整 25%。桌面可用 `-` / `+`（或 `=`）操作，Command/Ctrl 组合保留给浏览器。缩放仅作用于地图，保持正方形视口和玩家跟随；走近店铺时必要时暂时缩小以展示完整店铺，离开后恢复选择的比例。店内对话或阅读时不触发地图缩放。
