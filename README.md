# 新参者 · 人形町七日

中文文学推理小游戏。根据用户提供的《新参者》EPUB制作的浓缩改编，包含原著案件剧透；对话、七日期限、调查门槛、部分证言与地点布局为游戏化创作。没有复制或部署原书文件。

## 运行

使用任意静态服务器提供 `dist/`，例如 `python3 -m http.server 4173 --directory dist`。

## 内容与机制

- 三条示意街区、九个可访问地点，点击店铺或使用左右方向键切换街道。
- 每天六点调查精力，漫游、重读与推理不耗精力。
- 证言和证据组合解锁三个人物追问。线索和人物内容见 `dist/data.mjs`。
- 每日总结支持一段自由记录及最多三条证据。进度保存到当前浏览器 localStorage。
- 第七日日终截止，可提前提交完整答案，成功结局要求凶手、动机和三条证据均成立。
- `dist/engine.mjs` 保存纯状态规则，`dist/app.js` 实现交互，`dist/style.css` 实现响应布局。
- 街景图片由 ImageGen 生成，为艺术化想象，三街区共用一幅插画，非实景复原。

## 校验

`node tests/game.mjs`：运行 200 种不同走访顺序，验证期限内线索可达、精力、前置条件、推理与结案规则。使用当前 Node 版本。

本次未进行浏览器自动交互或截图测试。
