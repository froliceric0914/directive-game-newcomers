# 叙事与来源

目标是让玩家通过街道、人物、日常物品和原文，逐渐认识三井峰子。秘密不等于杀人动机；收获可以是理解一个人，而不是得到犯罪证据。

## 来源与改编

- 原著：《新参者》，东野圭吾著，岳远坤译；正文由用户提供的本地 EPUB 提取。
- 现有短对话基于第一章加贺回仙贝店确认田仓是否穿着西装上衣的场景，界面标明为情节改写。
- 全文章节保留对应 EPUB 的全部非空段落；不以游戏概要替代原著。
- 地图来自用户提供的人形町车站示意图，是艺术化的相对布局，不是实测地图。
- 现实商店与虚构店铺的身份关系不能仅凭建筑类型断言。地图中的关联阅读说明保存在 `data/locations.json`。

## 内容数据

- `characters.json`：23 个人物条目、24 张头像（加贺两种着装），角色与地点关联。
- `relationships.json`：现有已确定关系的部分索引，不代表完整人物关系图。
- `clues.json`：当前实现的仙贝店见闻，保留出处、原文片段和非定罪性质。
- `locations.json`：九个地图地点、待加入的叙事地点、NPC、全文映射和章节元信息。
- `phases.json`：当前原型阶段与尚未实施的章节草案。

## 暂存的三章方向

1. 日本桥的人们：认识街区，理解人们隐藏的日常心事。
2. 峰子的足迹：重建她作为母亲、朋友、翻译和重新开始生活的人的面貌。
3. 峰子之死：把已有的人物与物件关系汇合到案件。

以上是用户提出的叙事方向，不是已启用的关卡。章节地图、警局、事务所、公寓、剧场、岸田家等新场景的组织方案尚未定稿；本次目录调整不恢复这些功能的实现。没有对应人物的头像或地点图片时，不生成虚构人物、事件或线索。
