# Location Visual Brief

## Purpose

地点背景应让玩家一眼辨认环境，同时安静地服务于阅读与探索，不与对话和操作界面争夺注意力。与故事有关的物件可以自然存在于场景中，为未来的线索发现、NPC 互动、书签和其他地点功能预留可能。

`data/location-visuals.json` 是地点视觉元数据的机器可读来源；本文只提供生成背景和设计场景时便于阅读的美术指导。

## Global V1 Rules

- 统一采用 16:9 横向构图，V1 使用固定静态背景。
- 背景中不绘制 NPC 或加贺；人物继续使用透明头像叠加。
- 为固定 NPC 位置和对话、互动 UI 保留清晰的安全区域。
- 每个地点只突出 1–2 个标志物，其他内容用于建立真实环境。
- 标志物应自然融入场景，避免发光、描边或任务标记式强调。
- 控制陈设密度，避免无关杂物抢占阅读和交互空间。
- 不虚构小说事实；明确区分原著支持的细节与纯视觉构图建议。

## Location Reference

### 峰子公寓

**Visual identity**  安静整洁的单人居所，保留普通生活突然中断的感觉。

**Signature objects**  电脑桌；完整的起居空间。

**Composition**  单人床、书架、沙发、小桌、报刊架和小厨房共同构成生活环境；电脑桌与桌面可供调查，中央偏右留出人物区域。

**Avoid**  阴暗犯罪现场气氛、血迹、夸张破坏或背景人物。

### 仙贝店

**Visual identity**  传统、日常，带有熟悉的街坊店铺感。

**Signature objects**  成排陈列的袋装或盒装仙贝；玻璃展示柜。

**Composition**  木质货架与手写价签形成主要背景，柜台前留出 NPC 位置和对话安全区。

**Avoid**  高级旅游纪念品店质感、过度包装或背景人物。

### 料亭

**Visual identity**  安静克制、带年代感的传统料理空间。

**Signature objects**  木格栅；和式座席。

**Composition**  用障子、拉门、暖黄灯光和料理工作区建立纵深；左右分别预留人物位置，关键陈设保持可见。

**Avoid**  现代高级酒店风格、NPC 遮住关键物件或背景人物。

### 陶瓷器店

**Visual identity**  整齐但略显拥挤的老店，物件丰富而生活化。

**Signature objects**  满墙的碗、杯、盘与陶器陈列。

**Composition**  白瓷、青花瓷和土色陶器铺满木质开放货架；柜台前留人物区，日用品区可容纳故事物件。

**Avoid**  现代精品画廊感，或把厨剪处理成醒目的任务道具。

### 钟表店

**Visual identity**  旧式、安静，让不同钟表共同形成强烈的时间感。

**Signature objects**  满墙挂钟；带放大镜与工具的维修桌。

**Composition**  挂钟、腕表柜台和老式座钟形成层次，柜台前保持人物与对话空间。

**Avoid**  所有钟表时间完全一致、奢侈腕表专卖店风格或背景人物。

### 水天宫

**Visual identity**  城市中的安静神社，气氛带有期待与祈愿感。

**Signature objects**  子宝犬铜像；神社参拜区域。

**Composition**  石板路引向神社建筑，子宝犬置于前景至中景并清楚可辨，侧边留人物区。铜像应支持玩家日后重新理解“小狗”的含义。

**Avoid**  把子宝犬放大成任务标记，或让人物直接出现在背景中。

### 西饼店

**Visual identity**  比传统店铺更明亮、年轻、柔和。

**Signature objects**  陈列蛋糕与泡芙的玻璃甜点柜。

**Composition**  浅色木材、包装盒和纸袋围绕展示柜组织，柜台前留出 NPC 位置。

**Avoid**  传统和果子店、大型连锁咖啡店风格或背景人物。

### 樱花筷子

**Visual identity**  传统、生活化，具有家庭经营小店的温度。

**Signature objects**  成排筷子；成对陈列的小木盒。

**Composition**  不同长度和纹样的筷子形成陈列墙，包装台前保留人物与 UI 空间。

**Avoid**  把筷子主题处理成夸张符号，或在背景中绘制人物。

### 保洁公司

**Visual identity**  朴素实用的办公室，带有故事进入案件转折处的秩序感。

**Signature objects**  文件堆与办公桌；工作排班表。

**Composition**  文件柜、电话、纸质文件和荧光灯构成工作环境，办公桌前留人物区。

**Avoid**  大型现代企业总部、豪华办公室或背景人物。

### 民间艺术品店

**Visual identity**  温暖传统，陈设呈现多年累积而非刻意布展。

**Signature objects**  木雕；成组民艺摆件。

**Composition**  陶器、编织物、木盒与旧家具形成丰富层次，柜台前保持人物安全区。

**Avoid**  现代艺术画廊感、过度整齐的陈列或背景人物。

### 日本桥警署

**Visual identity**  朴素克制、以整理事实和推理为目的的实用空间。

**Signature objects**  调查桌；文件柜。

**Composition**  办公桌、电话、文件夹、白板与荧光灯构成警署环境；左侧或中央可放加贺，中央偏右保留主要 UI 区域。

**Avoid**  美剧式大型作战室，或用过多背景细节挤占界面空间。

## Future Use

这些视觉元数据未来可用于背景图生成、地点卡片、线索与证物摆放、NPC 定位、章节或书签视觉标记、环境呼应，以及让玩家重新发现故事细节的“小确幸”时刻。它们是后续可能性，不是当前 V1 的实现要求。
