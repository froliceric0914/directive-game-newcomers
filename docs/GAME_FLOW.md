# 游戏流程

## 当前实现

1. 玩家作为加贺，在人形町示意街区漫游。
2. 走近店铺后，手帐显示该地点与对应原著篇章。
3. 仙贝店入口自动打开和风对话卡片；其他地点保留地点手帐和全文入口。
4. 仙贝店的短对话结束后，可以记下关于西装上衣的见闻。
5. 当前对话提供简短原文；地点提供独立的篇章全文入口，不以完成对话为前提。
6. 片段在卡片内连续滚动，每次打开从头开始，不记录位置。全文展开为全屏滚动阅读，退出后返回原界面，不立即重复触发进店。
7. 小传马町首页与人形町地图共用一条十节点故事进度：峰子公寓完成后进入九章阅读；章节在警局保存判断后完成并推进下一章。

九个现有地点与七章全文已关联。水天宫支持第四、五章切换；现实店名与小说店名不能确认相同时，明确标注为关联阅读。完整映射在 `data/locations.json`。

## 操作

| 场景 | 按键 | 操作 |
| --- | --- | --- |
| 街道 | 方向键 | 长按连续平滑移动 |
| 街道 | E / J / R / H | 访问 / 手帐 / 当前地点原著 / 回到车站 |
| 街道 | +、= / − | 放大 / 缩小 |
| 店内 | T / J / R | 对话 / 手帐 / 阅读 |
| 对话、手帐 | E | 当前主操作 |
| 对话 | ← / → | 上一句 / 下一句 |
| 阅读 | 1 / 2 | 简短片段 / 全章（片段仅在已接入场景提供） |
| 阅读 | 方向键、PageUp、PageDown、空格 | 原生滚动 |
| 全文 | B / G | 保存当前书签 / 回到已有书签 |
| 多篇章地点 | C | 聚焦篇章选择框 |
| 全局 | Esc | 关闭 |
| 全局 | Tab、Shift+Tab / Enter、空格 | 选择 / 激活按钮 |

输入框、输入法组合输入、Command/Ctrl/Alt 组合键不被拦截。触屏提供方向按钮和对应 CTA。失焦、打开卡片时清除持续移动输入。

## 状态与范围

- 对话进度与仙贝店见闻在本次页面会话中保留。
- 街道碰撞按原格点计算；绘制在格点之间插值。
- 地图视窗保持正方形，支持 50%–200% 缩放，靠近商店时优先容纳整家店。
- 故事节点按 `future → current → completed` 推进；有地图地点的章节会在人形町自动定位，没有地图地点的章节直接使用全文阅读器。
- `src/app.js`、`src/engine.mjs`、`src/data.mjs` 是保留的早期七日推理版本，当前入口不加载它们。

## 全文续读

全文以 `readerProgress:<chapterId>` 保存 0–1 的内容相对进度，滚动后延迟 200ms 保存，退出前立即保存。每章一个独立书签，键为 `readerBookmark:<chapterId>`。仅存本浏览器，无后端；片段不读取或写入任何进度。全文正文宽度约 720px、字号 19px（手机 18px）、行高 1.8、段距 1.1em。
